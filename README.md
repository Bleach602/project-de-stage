Plateforme de Promotion & Gestion Électronique des Candidatures (IFP)

Une solution web complète et moderne conçue pour digitaliser l'écosystème d'admission d'un Institut de Formation Professionnelle. La plateforme simplifie l'expérience des candidats lors de leur inscription en ligne tout en automatisant la gestion administrative et le traitement des dossiers pour l'institution.
Key Features (Fonctionnalités Clés)
Portail de Promotion Institutionnelle

    Vitrine Dynamique : Présentation attrayante des filières, programmes de formation et diplômes.
    Orientation Candidat : Interface intuitive permettant de consulter les spécialités et les débouchés.

Gestion Intelligente des Candidatures

    Inscription en Ligne Simplifiée : Formulaire dynamique multi-étapes pour la saisie des informations et le choix des spécialités.
    Génération Automatisée de Fiches : Création instantanée de la fiche d'inscription administrative au format PDF lors de la confirmation.
    Stockage Sécurisé Cloud : Archivage et sauvegarde automatique des documents et pièces justificatives des candidats sur le Cloud.
    Suivi de Dossier : Consultation en temps réel du statut de la candidature.

Administration & Traitement (Back-Office)

    Tableau de Bord Administrateur : Validation, gestion et filtrage des dossiers de candidature.
    Sécurité & Gestion des Accès : Contrôle des accès basé sur les rôles (Candidat, Administrateur).

Tech Stack (Technologies Utilisées)

    Backend : Java, Spring Boot (Spring MVC, Spring Data JPA, Spring Security)
    Frontend : HTML5, CSS3, JavaScript, Thymeleaf
    Base de données : PostgreSQL
    Document & Cloud : Génération PDF (iText / JasperReports), Stockage Cloud (AWS S3 / Cloudinary)
    Build & Outillage : Maven, Git/GitHub
